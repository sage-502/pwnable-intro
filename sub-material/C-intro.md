## 1. C언어

**C는 시스템과 가장 가까운 고급언어**로, **메모리·하드웨어에 직접 접근**할 수 있는 강력한 문법을 가진 절차지향 언어.

### C언어 특징

| 특징 | 설명 |
| --- | --- |
| **절차지향 언어** | 코드가 순차적으로 실행되며, 함수 단위로 구조화함. |
| **고성능** | 기계어에 가까워서 실행 속도가 빠르고 시스템 자원 직접 제어 가능. |
| **저수준 접근** | 포인터를 통해 메모리 주소 직접 조작 가능. |
| **이식성** | 대부분의 운영체제에서 컴파일만 하면 실행 가능. |
| **컴파일 언어** | 코드를 먼저 컴파일해서 기계어로 변환 → 실행파일 생성. |

### C 프로그램 기본 구조

```c
#include <stdio.h>    // 입출력 라이브러리 포함

int main() {          // 프로그램 시작점 (main 함수)
    printf("Hello, world!\n");  // 화면에 문자열 출력
    return 0;         // 프로그램 정상 종료
}
```

### 구성 설명

| 부분 | 설명 |
| --- | --- |
| `#include` | 컴파일 전에 필요한 코드(헤더파일)를 포함 |
| `main()` | 프로그램의 진입점 (필수) |
| `{ ... }` | 코드 블록 (함수 본문 등) |
| `return 0;` | OS에 종료 상태를 반환 (0은 정상 종료) |

## 2. 변수

- 정수형:  `int`, `long`, `short`
- 실수형:  `float`, `double`
- 문자 :  `char`
- 크기 확인: `sizeof(type)` (플랫폼/컴파일러에 따라 다름 — 32/64비트 주의)
    
    ```c
    int a = 3;
    char *s = "hi";
    int *p = &a;
    ```
    

> **참고:** 타입별 크기가 다르므로, 이후 다룰 오프셋 계산에서 고려해야 함.(예: `int` 4바이트, 포인터 8바이트(64bit))
char는 작은 정수가 저장됨.(아스키코드 값으로 해석되서 문자)
> 

### [심화] 변수의 종류와 수명

| 변수 종류 | 선언 위치 | 생존 기간 | 접근 범위 |
| --- | --- | --- | --- |
| 전역 변수 | 함수 외부 | 프로그램 종료까지 | 어디서든 접근 가능 |
| 지역 변수 | 함수 내부 | 함수 실행 중에만 | 함수 내부에서만 접근 가능 |
| 정적 변수 | 함수 내부(지역)/함수 외부(전역) | 프로그램 종료까지 | 선언 위치에 따라 접근 범위 변동 |
- **전역 변수:** 함수 바깥에서 선언 → 모든 함수에서 사용 가능
- **지역 변수:** 함수 안에서 선언 → 함수 끝나면 사라짐
- **정적 변수:**  `static` 키워드 → 처음 한 번만 초기화, 값 유지

```c
int global = 1;          // 전역 변수
int func(int a) {
    static int count = 0; // 정적 변수
    int temp = a + 1;     // 지역 변수
    return temp;
}
```

## 3. 입출력

- 출력: `printf("format", ...)` — 포맷 문자열(`%d`, `%s`, `%p`) 중요
- 입력: `scanf`(주의), `fgets`(권장), `gets`(사용 금지)

```c
char buf[16];
fgets(buf, sizeof(buf), stdin); // 안전
// scanf("%s", buf); // 공백 무시, 버퍼오버플로우 주의

```

> **참고:**  `scanf`/`gets` 같은 입력 함수는 버퍼 오버플로우로 이어질 수 있음. `printf` 포맷 스트링은 별도의 취약점(Format string)을 만든다.

## 4. 조건문과 반복문

- 조건: `if`, `else`, `switch`
- 반복: `for`, `while`, `do-while`

```c
//i를 0에서 시작, i가 10보다 작을 동안, i를 1씩 키우며 반복
for(int i = 0; i < 10; i++){ 
	printf("%d\n", i); //i값 출력
}

if(0 < 1){ //만약 0<1 이 참이라면
	printf("true\n");
}
else{ //아니라면
	printf("false\n");
}
```

> **참고:** 반복문에서 인덱스/경계 체크를 못하면 배열 범위 초과로 오버플로우가 발생한다. (컴퓨터가 segmentation fault 던지고 “못해요” 시전함)

## 5. 함수

하나의 **특정 작업 또는 기능**을 수행하도록 작성된 **코드 블록**이며 ,필요할 때 호출하여 재사용할 수 있는 단위.

- 프로그램 내에서 중복되는 작업을 묶어 하나의 이름으로 정의하고,
- 입력값(매개변수)들을 받아서 내부 연산을 수행한 후
- 출력값(반환값)을 돌려줄 수 있다.

### 함수의 기본 형태

```c
반환형 함수이름(매개변수들) {
    // 함수가 할 일
    return 반환값;
}
```

| 구성 요소 | 설명 |
| --- | --- |
| **반환형(Return type)** | 함수가 실행된 후 돌려주는 값의 자료형 |
| **함수 이름(Function name)** | 함수를 식별하고 호출하기 위한 이름 |
| **매개변수(Parameter)** | 함수 외부에서 전달받는 입력 값들 |
| **본문(Body)** | 함수가 실제로 수행하는 작업 (코드 블록 `{}` 안) |
| **`return`문** | 계산된 값을 반환하고, 함수의 실행을 종료 |

### 예시:

```c
int add(int a, int b) {
    return a + b;
}
```

- `int` → 이 함수는 정수를 반환해요
- `add` → 함수의 이름 (원하는 이름 가능)
- `(int a, int b)` → 이 함수는 두 개의 정수를 입력받아요
- `return a + b;` → 두 수를 더한 값을 돌려줘요

### 함수 호출 (함수 사용하는 법)

```c
int result = add(3, 5);  // result에 8이 저장됨
```

> **참고**: 함수의 반환형과 실제 반환값의 타입이 동일해야 함. 
void의 경우 반환값 없음.

## 6. 포인터

- 메모리의 주소를 담는 변수 타입
- 선언/역참조: `int *p = &a; *p = 5;`
- 연산: `p + 1`은 타입 단위로 이동 (`int`면 4 또는 8바이트)
- 배열과 포인터: `arr[i] == *(arr + i)`

```c
int arr[4] = {1,2,3,4}; //배열 이름(arr)은 배열의 시작 주소를 나타냄
int *p = arr; //q가 가르키는 공간에 있는 자료는 int 타입
int v = *(p + 2); // arr[2]
```

> **주의:** 잘못된 주소 접근 → 오류. 포인터 타입도 중요.
>

## 7. 동적할당

- 함수: `malloc`, `calloc`, `realloc`, `free`
- 사용 후 `free()` → 포인터를 NULL로 설정 권장

```c
//int타입 자료를 넣을 수 있는 공간을 3개 만들기(메모리 할당)
int *p = (int*)malloc(3*sizeof(int)); 
p[0] = 1; p[1] = 2; //배열처럼 인덱스로 접근 가능
free(p); //사용 후 만들었던 공간 반납(메모리 해제)
p = NULL; //포인터가 갈 길을 잃음 -> NULL로 안전하게 처리하기
```

> **주의:** malloc()의 기본 반환 타입은 `void*` , 포인터의 타입에 맞춰 형 변환이 필요함.

## 컴파일 & 실습용 gcc 한줄

- 기본 디버깅 심볼 포함:

```bash
gcc -g hello.c -o hello
```

- **학습용(취약하게 만듦)** — VM/로컬에서만:

```bash
gcc -g vuln.c -o vuln -fno-stack-protector -z execstack -no-pie
```

> 설명: -fno-stack-protector 스택 가드 끔, -z execstack 스택 실행 허용, -no-pie 주소 랜덤화 제거. (아직 몰라도 괜찮아요)
