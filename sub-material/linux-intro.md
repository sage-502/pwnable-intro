# 🌱리눅스 기초 생존 시트

## 1. 리눅스란

- 유닉스 계열 오픈소스 OS
- 대부분 CLI 환경 사용
- 시스템 해킹에서 왜 중요한가? → 리눅스에서 돌아가는 바이너리 대상 실습 많음
- 다양한 배포판(Ubuntu, Debian, CentOS, Arch 등)

## 2. 디렉터리 구조

리눅스 계층 구조는 트리 구조로 되어 있으며, 모든 파일 시스템의 최상위인 **루트 디렉터리(`/`)** 에서시작한다.

| 디렉터리 | 용도 |
| --- | --- |
| `/` | 루트 디렉토리 |
| `/home` | 사용자 디렉터리 |
| `/bin`, `/sbin` | 필수 명령어, 시스템 명령어 |
| `/etc` | 설정파일 |
| `/var` | 로그 등 가변 데이터 |
| `/tmp` | 임시 파일 |
| `/dev` | 장치 파일 |
| `/proc`, `/sys` | 커널/시스템 정보 |

> **참고**: 지금은 `/`, `/home`, `/bin`,  `/tmp`  정도만 알아도 돼요.
>

## 3. 쉘과 커널

- 커널: 하드웨어와 가장 가까운 계층, 리소스 관리
- 쉘: 사용자의 명령어 입력을 해석(bash, zsh 등)
- 쉘에서 명령어 입력 → 커널에게 전달 → 하드웨어에서 처리

> **참고**: 터미널은 사용자가 컴퓨터와 텍스트 명령으로 소통하는 창으로, 명령 입력창을 의미. 이 명령을 해석하는 프로그램이 쉘
>

## 4. 기초 명령어

| 명령어 | 설명 |
| --- | --- |
| `ls` | 현재 디렉터리의 파일 및 폴더 목록 출력 
-l 옵션 : 상세 정보(권한, 크기 등) 출력
-a 옵션 : 숨김 파일(`.` 으로 시작)도 출력 |
| `cd` | 디렉터리 이동 (예: `cd /home/user`) |
| `nano` , `vim` , `vi` | 터미널 기반 텍스트 편집기 |
| `cat` | 파일 내용 출력 (cat filename.txt) |
| `echo` | 문자열이나 변수 값을 터미널에 출력하는 명령어 (echo meow) |

## 6. 파일 소유자와 권한

리눅스에서는 각 파일/디렉터리에 대해 누가 무엇을 할 수 있는가를 정하는 **권한 체계**가 존재한다.

### 사용자 종류

- **소유자(user)**: 파일을 만든 사람.
- **그룹(group)**: 해당 파일에 대해 권한을 가진 사용자 그룹.
- **기타(others)**: 소유자도, 그룹도 아닌 나머지 모든 사용자.

### 권한 종류(행위)

각 사용자 주체에 대해 3가지 권한 부여 가능:

| 기호 | 의미 | 설명 |
| --- | --- | --- |
| `r` | read | 읽기 (파일이면 내용 열람, 디렉터리면 목록 조회) |
| `w` | write | 쓰기 (파일이면 수정, 디렉터리면 파일 생성/삭제) |
| `x` | execute | 실행 (파일이면 실행, 디렉터리면 진입 가능 여부) |

### 권한 표기 예시

```bash
$ ls -l hello
-rwxr-x--x 1 user group 1234 Nov 11 12:00 hello
```

| 위치 | 설명 |
| --- | --- |
| `-` | 파일 타입 (`-`: 일반파일, `d`: 디렉터리 등) |
| `rwx` | 소유자 권한: 읽기/쓰기/실행 가능 |
| `r-x` | 그룹 권한: 읽기/실행 가능, 수정은 불가 |
| `--x` | 기타 권한: 실행만 가능 |

> Tip: 권한은 순서대로 3자리씩 끊어서 해석.
> 

### [심화] SetUID / SetGID

특수 권한으로, 실행 파일에 설정되면 아래처럼 동작:

| 권한 | 설명 |
| --- | --- |
| **SetUID (`s` in owner 실행 권한 자리)** | 실행 시 '파일 소유자의 권한'으로 실행됨. 주로 root 권한 상승에 사용됨. |
| **SetGID (`s` in group 실행 권한 자리)** | 해당 파일을 실행하거나 디렉터리에 접근하는 사용자는 그룹 권한을 물려받음. |

> ⚠️ setuid/setgid는 취약점 공격 지점이 되기도 하므로 포너블 관점에서 의미 있음.
> 
> 
> 나중에 “권한 상승” 관련 주제로 연결 가능.
>
