# 📋 x86 32-bit Assembly Cheat Sheet

- x86 32bit Assembly에서 자주 사용되는 기본 명령어
- Intel Syntax 기준
- 명령어의 피연산자는 `목적지, 소스` 순서

## 1. 데이터 이동

| 명령어    | 설명          | 예시                                 |
| ------ | ----------- | ---------------------------------- |
| `mov`  | 데이터를 복사함    | `mov eax, ebx` → EAX = EBX         |
| `lea`  | 메모리 주소를 계산함 | `lea eax, [ebp-4]` → EAX = EBP - 4 |
| `push` | 스택에 값을 저장함  | `push eax` → ESP -= 4              |
| `pop`  | 스택에서 값을 꺼냄  | `pop eax` → ESP += 4               |

## 2. 산술 및 논리 연산

| 명령어   | 설명             | 예시                               |
| ----- | -------------- | -------------------------------- |
| `add` | 덧셈을 수행함        | `add eax, 4` → EAX += 4          |
| `sub` | 뺄셈을 수행함        | `sub esp, 0x10` → ESP -= 16      |
| `and` | 비트 AND 연산을 수행함 | `and esp, 0xfffffff0` → 16바이트 정렬 |
| `xor` | 비트 XOR 연산을 수행함 | `xor eax, eax` → EAX = 0         |

## 3. 비교 및 분기

| 명령어           | 설명                       | 예시              |
| ------------- | ------------------------ | --------------- |
| `cmp`         | 두 값을 비교하고 플래그를 설정함       | `cmp eax, 5`    |
| `test`        | 비트 AND 연산으로 플래그를 설정함     | `test eax, eax` |
| `jmp`         | 지정된 주소로 무조건 이동함          | `jmp 0x8048000` |
| `je` / `jz`   | 두 값이 같거나 결과가 0이면 분기함     | `je label`      |
| `jne` / `jnz` | 두 값이 다르거나 결과가 0이 아니면 분기함 | `jne label`     |

## 4. 함수 호출 및 스택 관리

| 명령어     | 설명                        | 예시          |
| ------- | ------------------------- | ----------- |
| `call`  | 복귀 주소를 스택에 저장하고 함수를 호출함   | `call vuln` |
| `ret`   | 스택에서 복귀 주소를 꺼내 해당 주소로 이동함 | `ret`       |
| `leave` | 현재 스택 프레임을 정리함            | `leave`     |
| `nop`   | 아무 작업도 수행하지 않음            | `nop`       |

## 5. 자주 등장하는 명령어 예시

```
mov eax, [ebp+8]        ; 첫 번째 함수 인자를 EAX에 저장함
lea eax, [ebp-0x20]     ; 지역 변수의 주소를 EAX에 저장함

sub esp, 0x20           ; 스택 공간 32바이트를 확보함
and esp, 0xfffffff0     ; ESP를 16바이트 경계로 정렬함

xor eax, eax            ; EAX를 0으로 초기화함

call vuln               ; vuln 함수를 호출함
leave                   ; 스택 프레임을 정리함
ret                     ; 호출한 위치로 복귀함
```

※ `[주소]`는 해당 주소에 저장된 메모리 값을 의미하며, `lea`는 메모리 값을 읽지 않고 유효 주소만 계산한다.
